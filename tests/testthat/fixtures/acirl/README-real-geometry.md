# ACIRL real-geometry fixtures (PLAN-06 R-6.3a)

Generated by `generate-real-geometry.R`. These **supersede** the fixtures
described in `README.md`, which must not be used as a layout model.

## Why these exist

The original fixtures were built from PLAN-06's *prose description* of the
water-sheet layout, never measured from a real workbook. Consequence, measured
2026-07-29 … 2026-08-01:

- the adapter passed **100% of its tests**, and extracted **zero rows from all
  147 real ACIRL workbooks** that `match()` claims;
- 612 of 986 real water sheets were skipped `no_field_block`.

The old fixtures encode a shape that occurs **zero times** in the real corpus.

| property | old fixtures | real corpus |
|---|---|---|
| `Units` marker shares a row with `Site Name` | yes | **never** — 0 of 640 |
| field-label column | column 1 | the `Site Name` column (2 dominant; also 1, 3, 7) |
| `Date` row | below the header | **above** the `Site Name` row — 640 of 640 |

## Measured geometry — the provenance of every structural property

Measured over the whole corpus at
`assets/` (213 ACIRL workbooks; 986 water sheets, of which 640 carry a
`Site Name` row; 50 dust-results sheets). Every rule below held on **every**
sheet measured:

| rule | holds |
|---|---|
| `units_col == site_col + 1` | 640/640 |
| `first_feature_col == units_col + 1` | 640/640 |
| date-label column `== site_col` | 640/640 |
| `date_row == site_row - 1` (date row is **above**) | 640/640 |
| `units_row == site_row - 4` (593) or `- 3` (47) | 640/640 |
| ALS-reference row at `site_row - 3` (442) or `- 2` (198), label in `site_col` | 640/640 |
| `ALS Sydney Report No.` row present at all | 640/640 |

The fixtures use `site_col = 2`, `site_row = 10` — the dominant real values.

**Reference workbook for the water-sheet layout:**
`assets/unprocessed/dust/2400-7399-04 April 2024  Monthly Blaxland WMF .xls`,
sheet `Sampling Sites 1`. Its values were cross-checked against the sibling
PDF `…2400-7399-04 April 2024  Monthly Blaxland WMF .pdf` and against the live
DB (legacy import) — all three agree.

### Dust sheets

Measured across all 50 real dust-results sheets; every one carries every anchor
(`GAUGE NO.`, `Month`, `INSOLUBLE SOLIDS`, `*COMBUSTIBLE MATTER`,
`INCOMBUSTIBLE MATTER`, `Exposure Days`, `g/m²`) and all use two gauges.

1. **Quarterly sheets repeat the month-block** — 2 gauge rows + one
   `Exposure Days` row per month, up to 4 blocks. Reference:
   `2400-7286-09 September 2023 Quarterly Blaxland ( Water & Dust) WMF.xls`
   (4 blocks). The main fixture carries 3.
2. **`INCOMBUSTIBLE MATTER` is column-shifted** — header in column 12, values in
   column **13**. A merged-cell artifact; the legacy reader compensated with
   `coalesce(last_col, last_col - 1)`. Present in every real sheet inspected.
3. **Below-detection values** appear as `<0.1` in an otherwise numeric column.
   Reference: the September 2023 quarterly.
4. **`Month` is not trustworthy** (A77): it disagrees with
   `Dust Observations.EXPOSURE DATE` in **8 of 64** real gauge-blocks, and in 6
   of those holds the *collection* date instead. Reference for the fixture
   `2400-9999-14`: `2400-7453-06 June 2025 Quarterly Blaxland WMF .xls`, whose
   `Month` says 2025-06 while its exposure period is 2025-05 → 2025-06 over 31
   days. **But neither sheet is authoritative** — in
   `2400-7538-02 Monthly Blaxland WMF .xls` the *Observations* sheet is stale by
   two years while `Month` is right. Hence: cross-check, never auto-prefer.

### Field-vs-ALS values (A75)

The main fixture's `pH`/`pH Value` and
`Electrical Conductivity`/`Electrical Conductivity @ 25°C` pairs are the
value-diff test data. The **ALS-copy** rows carry:

    pH Value                        6.42, 6.61, 6.75, 5.94
    Electrical Conductivity @ 25°C  1360, 805,  698,  117

A companion ALS fixture must reproduce these **exactly**, so the value test can
identify them as copies. The field rows deliberately differ
(`pH` = 5.90, 6.10, 6.60, 6.40), reproducing the real field-vs-lab split — the
same split behind the 2026-07-24 ruling that the field pH wins.

## Calibration — these fixtures reproduce the real failure

Run against the **current, unfixed** adapter (2026-08-01):

| fixture | rows extracted |
|---|---|
| `2400-9999-01_Test_WMF.xlsx` (old synthetic) | **23** — the adapter looks healthy |
| `2400-9999-11_Real_WMF.xlsx` (real geometry) | **0**, 2 × `no_field_block` |
| `2400-9999-12_DustOnly_WMF.xlsx` | `match() == "no"` — not even claimed |

That 0 is the same result the adapter gives on all 147 real workbooks. **A
fixture that does not reproduce the failure would not have caught it** — this
is the known-positive calibration the old fixtures never had.

## Anonymisation (A3)

Structure is real; data is synthetic. Sites are `T.S01`/`T.S02`, gauges
`T.D01`/`T.D02`, work orders `ES9999001`/`ES9999002`, reports `2400-9999-*`.
No real lab values are committed — the numeric values are invented, and are
internally consistent only where a test needs them to be.
